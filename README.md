# Салон красоты

Учебное Android-приложение для администратора салона красоты. Проект создан в формате **вайбкодинга** — как практический эксперимент и способ обучения работе с ИИ при разработке приложений.

> Это учебный проект, а не готовое решение для использования в реальном салоне. Часть решений упрощена ради изучения Android-разработки и взаимодействия с ИИ.

## Возможности

- Авторизация администратора с демонстрационными учётными данными.
- Dashboard со статистикой за сегодня и загрузкой мастеров.
- Список записей с фильтром по мастеру.
- Создание записей с указанием клиента, услуги, мастера, даты и времени.
- Проверка формата даты и времени перед сохранением записи.
- Смена статуса записи: ожидание, выполнено или отменено.
- Просмотр мастеров, их специализаций, рейтинга и ближайших записей.
- Просмотр, добавление и удаление услуг.
- История записей и базовая аналитика.
- Локальная база данных Room для хранения данных.

## Технологии

- Kotlin
- Jetpack Compose
- Material 3
- MVVM
- Navigation Compose
- Room
- KSP
- Coroutines и Flow / StateFlow
- Coil для загрузки фотографий мастеров

## Требования

- Android Studio с поддержкой указанной версии Android Gradle Plugin.
- Android SDK 35.
- Устройство или эмулятор с Android 8.0 (API 26) или выше.

Основные версии библиотек и плагинов указаны в `gradle/libs.versions.toml`.

## Демонстрационный вход

- **Логин:** `admin`
- **Пароль:** `1234`

Учётные данные заданы в коде приложения. Такая авторизация предназначена только для демонстрации и не является безопасной для реального приложения.

## Данные и работа офлайн

Основные данные приложения хранятся локально в Room. Сетевой API и синхронизация не используются.

Фотографии мастеров загружаются по URL, поэтому их отображение зависит от наличия интернет-соединения и доступности источника изображений. Без интернета остальные основные функции приложения рассчитаны на работу с локальной базой данных.

При первом создании базы добавляются демонстрационные мастера, услуги и записи.

## Ограничения учебной версии

- Экран записей показывает записи только на текущую дату. Записи на другую дату сохраняются, но в этом списке не отображаются.
- Проверка занятости мастера при создании записи не выполняется.
- Изменять и удалять мастеров нельзя.
- Аналитика упрощена и предназначена для демонстрации работы с запросами Room.
- Авторизация не использует сервер и не защищает данные.
- Данные хранятся только локально на устройстве.

## О проекте

Проект создан для практики разработки Android-приложений и изучения того, как использовать ИИ в процессе написания кода: формулировать требования, получать реализацию по частям, проверять результат и исправлять ошибки.

Код и решения могут содержать упрощения и требуют проверки перед использованием в реальном продукте.
